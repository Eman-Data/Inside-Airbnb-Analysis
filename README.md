#Inside Airbnb Analysis

An end-to-end analysis of Airbnb listings across Paris, London, and Hong Kong — combining data cleaning, machine learning, NLP, and business intelligence to explore pricing trends, guest sentiment, and market performance.

📊 Key Components
Data Cleaning: Handling missing values, outlier removal, and preparing listings data for analysis and modeling.
Machine Learning: Regression models trained to predict listing prices, with performance compared using R² and error metrics.
NLP: Sentiment classification of guest reviews (positive/neutral/negative) using VADER, with keyword extraction from positive and negative comments.
Power BI Dashboard: Interactive visualization of listings, pricing, and market trends across the three cities.
